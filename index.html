热坩埚，慢一步

冶金实验室高温熔融安全微视频拍摄脚本。用一次“遇湿险情”和一次“搬运险情”，把样品、夹具、路线、落点拍清楚。

建议选题：坩埚熔融与热坩埚搬运9人全员出镜成片约2分50秒正确 / 错误示范对照
脚本导航选题与设定9人分工分镜与台词拍摄安全封面与交付

选题与设定

推荐主题：坩埚熔融实验中的遇湿喷溅与热坩埚搬运。切口聚焦冶金实验室真实动作，不泛讲“注意安全”。标题共7个汉字（含标点），符合≤15字要求。

类型安全情境短片
预计时长2分50秒
场景马弗炉 / 熔融操作区
选题查重：先把“熔融物遇湿 + 热坩埚转运”报给班长确认。若班里已有相近选题，可把题目收窄为“热坩埚转运险情与正确夹持”，避免与笼统的“实验室高温安全”撞题。

案例说明：脚本中的两个险情按高温熔融实验中常见、真实存在的事故机理编排；不冒称本校具体事故。若老师要求引用可核验的真实个案，请用导师或实验室安全员确认过的公开案例替换，并在片尾标出处，不编造时间、地点或伤者信息。

9人分工（保证每人有清楚的出镜点）

成员片中角色出镜 / 台词任务
成员1炉前操作员开场提出取坩埚；正确示范按本室SOP确认取样条件。
成员2着急的操作者错误示范主角；说“戴手套就够了”，之后接受同伴制止。
成员3同伴提醒者叫停错误动作；说清楚面屏、合适夹钳和干燥落点。
成员4安全讲述者串场旁白；解释水遇熔融金属会快速汽化并引发喷溅。
成员5样品准备者呈现“样品刚清洗、可能带水”的投料险情。
成员6坩埚搬运者呈现夹持和转运动作；正确示范缓慢、稳定搬运。
成员7路线观察员清理并确认通道，划定周边避让范围，沿途监护。
成员8事故复盘员用定格 / 回放说明第二个险情：夹持偏斜、路线受阻。
成员9现场联络员展示暂停、提醒撤离、报告老师 / 安全员的处置；带领结尾。

拍摄清单：每位成员至少有一个可辨认的正面或半身镜头；结尾全员同框。可在片尾字幕列出全体主创姓名与分工。

分镜与拍摄台词

时间码为剪辑目标，台词可按实际语速微调；剪完总时长控制在3分钟以内。

00:00–00:13

开场：炉温到了，要不要马上拿？

画面 / 声音

中景：炉前操作员看一眼炉子，旁边同学抱着坩埚钳靠近。屏幕短暂定格，切标题《热坩埚，慢一步》。

成员1：“到取样时间了，先把坩埚拿出来。”

成员2：“我戴着手套，直接夹就行吧？”

导演提示

不用点燃设备或打开热炉。用冷炉、关机炉和空坩埚取景；炉温数字可后期叠字模拟。

出镜：成员1、2、4（旁白/标题）
00:13–00:36

错误示范一：只戴手套，短钳探炉口

错误镜头（冷态摆拍）

成员2只戴普通手套，拿不匹配的短钳，身体探向炉口；同伴喊停，画面定格并出现红色“×”。不做真实高温操作。

成员3：“停！护目镜外还要按规程戴面屏；夹钳得适配坩埚，别探身硬夹。”

旁白 / 正确点

成员4旁白：“炉膛、坩埚和夹具都可能造成严重烫伤。手套不能替代面部防护，夹持不稳就可能失手。”

快速切到正确着装：护目镜加面屏、完整干燥的耐热手套、实验室规定的防护服和包脚鞋。具体装备以本室SOP为准。

出镜：成员2、3、4
00:36–01:01

正确示范：先查条件，再动手

正确镜头

成员1对照本室SOP和实验记录，确认允许取样的温度 / 开炉条件；成员3检查干燥、适配的专用夹钳与耐火承接位；成员7清出通道并做监护。

成员1：“取样温度和开炉条件先按本室SOP确认，不凭经验猜。”

成员3：“面屏、夹钳、落点和路线都确认了，再开始。”

镜头重点

给夹钳夹口、坩埚承接位、无障碍通道各一个近景。搬运演示全程使用空的冷坩埚。

出镜：成员1、3、7
01:01–01:34

险情一：带水样品靠近熔融金属

险情还原（不接触熔体）

成员5拿着标记为“刚清洗 / 干燥状态不明”的样品走向投料区。成员2准备接过，成员3立即抬手叫停。用红色闪切表现“如果投下去会怎样”，绝不真的投料、泼水或制造喷溅。

成员5：“样品刚洗过，表面看着差不多干了。”

成员3：“先停。干燥状态不明的样品不能进熔体。”

事故机理 / 正确处置

成员4旁白：“水接触熔融金属会迅速汽化、急剧膨胀，可能把金属液喷出，造成烫伤。”

正确做法：确认样品、坩埚和工具无水；需干燥或预热时，只按经批准的实验方法和SOP处理。状态不明就隔离、询问，不投料。

出镜：成员5、2、3、4
01:34–02:07

险情二：夹持偏斜，通道还有障碍物

错误镜头（空坩埚摆拍）

成员6用不合适的夹钳夹一只空冷坩埚，成员7指出路边有纸箱 / 杂物。模拟夹口偏斜后立即定格，不让坩埚掉落；用音效表现“险些失手”。

成员8复盘：“夹具不合、路线受阻，碰撞时坩埚可能倾斜，热物料会烫伤本人和旁人。”

正确镜头

成员7清出路线并提醒旁人退到警戒线外；成员6先用空冷坩埚检查夹持配合，再双手稳夹、平稳短距离转运，放到干燥、稳定的专用耐火承接位。不跨越他人，不急转、不奔跑。

成员7：“通道清了，落点干燥稳定；我在旁边看路。”

出镜：成员6、7、8
02:07–02:31

一旦出险：先停、提醒、报告

画面 / 台词

全员停止动作，成员9示意周围人退开并联系指导教师 / 实验室安全员。镜头切到应急联系卡和实验室应急预案位置。

成员9：“先停操作、提醒周围人避开，按实验室预案报告。有人受伤，马上启动校内急救流程。”

屏幕提示

“不围观、不自行清理熔融物、不泼水、不徒手拾取。”能量切断仅在安全且符合本室预案时进行。按现场应急预案处理。

出镜：成员9、全组背景
02:31–02:50

收束：四项确认，全员出镜

全员同框 / 轮流一句

成员1、5：“样品和工具，确认干燥！”

成员2、3、6：“防护到位，夹持稳定！”

成员7、8：“路线清楚，落点可靠！”

成员9带全组：“不确定，先停手，再问老师或安全员。”

片尾字卡

干燥 · 夹稳 · 清路 · 稳放

主创：9位组员姓名

指导教师：教师姓名

姓名以最终名单为准。可加课程 / 班级；不要把演绎情境写成真实事故报道。

拍摄安全控制

所有错误示范只拍冷态摆拍。不使用真实熔融金属，不把水或潮湿物放到热设备附近，不真的失手、倾倒或制造喷溅。涉及炉门的镜头只用冷却、断能并按实验室规定确认安全的设备；无法确认时用空镜加后期画面替代。
道具
空的冷坩埚、冷炉、合适夹钳、标注“状态不明”的干燥样品道具、胶带警戒线。
拍摄前
向实验室负责人报备；清走真实实验材料；确认电源 / 气源按场地要求处于安全状态。
危险镜头
用停格、红色闪切、音效和字幕表现后果，不靠真的危险动作完成画面。
信息准确
装备、温度、开炉、干燥 / 预热和应急流程以本实验室SOP及指导教师要求为准。
